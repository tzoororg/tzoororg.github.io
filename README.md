# tzoororg.github.io

GitHub User Pages root for tzoororg. Serves `/.well-known/assetlinks.json` so the
Android TWA (`io.github.tzoororg.us`) passes Digital Asset Links verification at the
host root. The app itself lives at https://tzoororg.github.io/DateAnalyze/ (repo: DateAnalyze).

The SHA-256 fingerprint in assetlinks.json is a placeholder until the Bubblewrap signing
keystore exists; replace it after the first AAB build.
